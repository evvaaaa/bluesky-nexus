bluesky_nexus.schema#

Contains the bluesky nexus schema model.

This relies on fields, attributes, links, etc. which are static, and NxGroups which are metaclasses generated by NXDL set through the “NEXUS_DEFINITIONS_DIRECTORY” and loaded through NxBaseClass.build("NXsomenxdlname")

property nxclass: NxAttribute#

A computed property for getting the NeXus NXDL class name from the python class name.

This field is serialized and dumped and then used for type discrimination in deserialization. It should never be replaced in subclasses.

classmethod from_dictionary(dictionary: dict) → T[source]#

Load the serialized NxGroup or subclass of NxGroup and initialize with it.

The “$nxclass” field has to be a subclass of the class calling this method, e.g NxObject.from_dictionary can produce an NxData, but NxData.from_dictionary can not produce an NxMonochromator.
